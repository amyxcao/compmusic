## Timbre-based Self-Similarity Matrix: Same Ol’ Mistakes

![Timbre SSM](sameoldceptogram.png)

This self-similarity matrix is based on timbre (MFCCs), meaning it highlights changes in texture and production rather than harmony. The strong diagonal line shows that each moment is most similar to itself. The larger square-shaped regions suggest repeated sections with similar instrumentation. Around the middle of the piece, there is a noticeable shift in similarity, which corresponds to what I hear as a change in density and energy. The structure becomes visible through these repeating blocks.
